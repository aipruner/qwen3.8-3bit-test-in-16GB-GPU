Generation speed depends on what you generate

Same server, same settings, MTP speculative decoding (--spec-draft-n-max 4), tokens/sec
Agent loop (tool calls)
111–115 t/s
Code (Python / HTML+JS)
100–113 t/s
English prose
80–85 t/s
Chinese prose
~80 t/s
MTP only pays off when the draft head guesses right. Structured, repetitive output (tool-call JSON, code) is predictable; free-form prose is not. Benchmarking a local model with chat prompts systematically understates its agent-loop speed.
